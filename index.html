Accede desde tu iPhone al proceso privado de firma de aplicaciones iOS mediante GitHub Actions y sus ejecutores macOS.

Firmar tu IPA

  1. En el repositorio privado, configura el certificado y el perfil como secretos de GitHub Actions.
  2. Sube una IPA propia al repositorio privado.
  3. Abre el flujo de firma, pulsa Run workflow y escribe la ruta del archivo.
  4. Descarga la IPA firmada desde Artifacts cuando termine.
